# Cinematic reflection avatars

20 fictional portraits generated with the built-in image generation tool. The final assets are `avatar-01.webp` through `avatar-20.webp`, each 256 × 256 pixels, WebP quality 78. Originals remain in the generator's output folder.

These images supply illustrative avatar stacks in Continue reflecting. They are decorative portraits rather than photos of actual respondents. New visits randomize the pool; the reflection shuffle replaces every portrait in each three-face stack.

## Shared generation prompt

Use case: photorealistic-natural. Asset type: square profile avatar for a reflection web app. Generate one single photorealistic cinematic head-and-shoulders portrait of a <subject>. Face centered, fully visible and filling most of the square, eyes sharply focused, comfortable space around head for a circular crop. Professionally cinematography-graded 35mm film still, soft amber key light, warm orange and copper highlights, restrained rich brown shadows, natural skin tones and realistic skin texture, very subtle film grain, shallow depth of field with soft warm neutral background. Premium warm intimate human mood. No text, no logos, no border, no collage, no extra people. Square image.
